## Interpretation

- **Tie-break** (`edges/tie-equal-hits`): Bash's `sort -rn | head -1` breaks equal hits by the reversed last-resort byte order of the whole `hits\tmid\tsummary` line — on this system's `sort` that is "greatest id first", which is the rule the port pins (highest hits, then greatest id, then greatest summary). PARITY here; the PORT-NOTE + PARITY.md row exist because a `sort -s` or a collating locale would leave Bash to awk's hash order instead.
- **Locale**: Bash under LC_ALL=en_US.UTF-8 on "Café résumé": exit 0, 1 observation(s) appended (C locale: 1). No difference observed on this system's locale tables.
- **awk -v escapes** (`awk-v/awk-v-backslash-summary`): a backslash sequence in a memory's `summary:` line is interpreted by `awk -v s="$summary"` when Bash writes the index row (`\t` → TAB splits the row's fields, `\n` → newline splits the row; the surfaced summary is cut at the tab); the port writes the bytes verbatim. Documented deviation (Bash artifact), reported and not counted.
- **`[[ -ge ]]` on a non-integer knob** (`edges/min-hits-non-integer`): Bash prints an arithmetic-syntax-error line naming the script's absolute path and line number, then exits 0 (the test is false); the port exits 0 silently. Exit code, stdout, and state match — stderr wording only, the same class as the documented `${2:?}` deviation. Reported and not counted.
- Everything else — every no-op path's silence and exit 0, the die paths' exit 1 + message, the verbatim observation content and field order, run_id auto-link, index.tsv and seen bytes, the stale index left after `rm`, the knobs, the semantic suffix — is byte-identical.
